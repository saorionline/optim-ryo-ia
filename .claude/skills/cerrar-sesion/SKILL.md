# Cerrar sesión — actualizar memoria

1. **Lee** `memoria/estado-actual.md` y `memoria/decisiones.md`.
2. **Reescribe** `memoria/estado-actual.md` con esta estructura (máximo ~40 líneas):
   ```
   # Estado actual — actualizado AAAA-MM-DD
   ## Hecho recientemente
   ## En curso
   ## Siguiente paso
   ## Bloqueos / preguntas para el operador
   ```
   Resume: qué cambió y dónde (rutas de archivos), no la conversación.
3. **Agrega** (no edites las anteriores) a `memoria/decisiones.md` cada decisión nueva:
   ```
   ## AAAA-MM-DD — Título corto
   - Decisión:
   - Motivo:
   - Reemplaza a: (si aplica)
   ```
4. Verifica que no escribiste secretos, llaves ni datos personales.
5. Muestra al operador un resumen de 3–5 líneas de lo que guardaste.
